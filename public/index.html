Your backup → three reports

  1. Export your POS backup

    Use the same ZIP format as ZBFS.ZIP. Keep the DBF files inside it; no need to extract anything.

  2. Import the file

    Tap Import backup ZIP. You can select a downloaded file or Google Drive when it appears in your phone's file picker.

  3. Read, filter and export

    Choose Receivables, Payables or Stock. Search, sort, export the filtered rows, or use Print / PDF.

Hidden header balances

Summary amounts start hidden whenever you open or reload the app. Tap the eye beside Summary balances to reveal or hide them. Report rows and exports keep their amounts.

Install on Android

Open this site in Chrome and use Install app or the browser menu → Add to Home screen. After installation, it can appear in compatible apps' Share / Send a copy menus for ZIP files.

Share the actual ZIP file, not a Drive link. Saving a file in Drive does not automatically open this app or refresh its reports. Import or share each new backup.

Clear all data

Tap Clear all data beside Import backup ZIP to remove the saved backup and empty every report. You will be asked to confirm. Refreshing the page keeps your data.

Your data

The latest backup is saved in this browser on this device. Closing, reopening or reloading the app keeps it. Importing another ZIP replaces the saved report only after it has been read successfully. They do not sync to other devices. Clearing browser data removes saved imports.

The app is a backup report viewer. It does not change your POS database. Stock valuation uses stored average costs, with stock checks shown below the report.

Install Nexus Pulse

Use the steps below if your browser does not show an install prompt.

  1. Open in your browser

    Open the app link in Chrome on Android. If you are inside ChatGPT, use Open in browser or copy the link into Chrome.

    Open app in a new tab ↗
  2. Keep your reports on your device

    Your backup is read and saved in this browser. No account is needed to use the report reader.

  3. Add it to your home screen

    Chrome menu ⋮ → Add to Home screen → Install, when offered. On iPhone, open in Safari and use Share → Add to Home Screen.

The install option depends on your browser. A home-screen shortcut may be offered instead of full installation.
